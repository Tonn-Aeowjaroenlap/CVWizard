# Roadmap

## Phase 0A — repository foundation

Versioned YAML evidence and claims models, offline validation, fictional fixtures, tests and privacy boundaries. No actual career-data ingestion or document generation.

## Recommended Phase 0B handoff

Before implementing ingestion, agree on a private sample inventory, source locator conventions, stable ID assignment rules, reviewer identity and approval audit process, redaction policy, handling of conflicting sources, and an explicit public-portfolio release rule. Obtain test data that can stay private and define acceptance cases for CV import as untrusted evidence. Keep generated wording separate from canonical facts.

Future phases may add reviewed ingestion, job-specific drafting, document generation and a public portfolio workflow. Each should consume the same evidence contract, add tests around attribution and privacy, and require human sign-off before publication or application submission. An API remains optional.
